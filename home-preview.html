Can a word avoid this forever?

Look at what each half contains

Both halves use the same letters, the same number of times. Only the order changes.

First half

a ×1 b ×1

Second half

a ×1 b ×1

The counts match. The order does not.

Mathematicians call this an abelian square: two adjacent blocks with the same letter counts, in any order.

It happens with longer blocks too.
